## 💼 Обо мне
- Пишу **надёжный backend на Python**: REST API, аутентификация, валидация, тестирование (`Pytest`).
- Работаю с **PostgreSQL**, **SQLAlchemy**, **Django ORM**, **RESTful-архитектурой**.
- Делаю фронтенд на **React** (компоненты, состояние, хуки, работа с API через fetch/axios)
- Знаю, как **интегрировать ИИ-модели через API** и готовить данные (`pandas`, `NumPy`).
- Умею **развёртывать и настраивать инфраструктуру** — опыт с серверами, сетями, мониторингом.
- Создаю **автоматизации**: например, отслеживаю вакансии на hh.ru с уведомлениями в Telegram.
- Готов к **удалённой работе**, быстро вникаю в контекст, ценю чистый код и командную работу.
